# Backseat Driver Workshop - Conj/2026

Slides and resources for the workshop.

**NB**: This is Work in Progress until and beyond September 29th (the workshop day).

Prerequisites:

An active AI subscription: Copilot and Cursor integrate most seamlessly, but any non-cloud agents will also work fine.

* [VS Code](https://code.visualstudio.com/) or fork (If you haven't picked yet, I can recommend [Cursor](https://cursor.com), it's my daily driver) (Antigravity sort of works, but is a clunky with Backseat Driver)
* [Babashka](https://github.com/babashka/babashka)
* [Java](https://www.java.com/)
* [Clojure CLI](https://clojure.org/)
* [Node.js](https://nodejs.org/)
* [Calva](https://calva.io/)
* [Calva Backseat Driver](https://github.com/BetterThanTomorrow/calva-backseat-driver)
* [Joyride](https://github.com/BetterThanTomorrow/joyride)

The slides (and my styling) wants this:

* [Markdown Preview Mermaid Support](https://github.com/mjbvz/vscode-markdown-mermaid)
* Dark mode theme activated

## Get started

1. Clone this repository to your computer.
2. Say **hello** in chat. The agent will know what to do to help you get things initialized.
